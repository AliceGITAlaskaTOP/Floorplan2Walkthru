# Сайт Floorplan2Walkthru

## Запуск и сборка

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Сборка создаёт `dist/`, который можно разместить на статическом хостинге. Сервер API для работы приложения не требуется. Планировки, настройки отделки и мебель сохраняются в localStorage пользователя. Панорамы и видео до экспорта ZIP находятся в памяти текущей вкладки.

`npm run build` также упаковывает самую крупную модель мебели в glTF с внешними буферами. Геометрия и текстуры сохраняются побайтно; каждый файл помещается в лимит статического хостинга 25 MiB. Для разработки используется исходный GLB.

## Возможности

- Три готовые планировки, одна с расставленной мебелью.
- Импорт SVG с разметкой CubiCasa и ZIP-проектов этого приложения.
- 3D-прогулка, выбор помещения на мини-плане, просмотр сверху.
- Редактор мебели, материалов и цвета поверхностей.
- Съёмка панорам 360° в 2K, 4K, 8K (ограничивается возможностями устройства), экспорт в ZIP.
- Русские основные элементы интерфейса, подсказки и сенсорное управление прогулкой.
- Просмотр готовых примеров в 2D, если WebGL 2 недоступен.

## Ограничения

Импорт JPG/PNG, распознавание произвольных SVG, многоэтажные здания, серверное хранение, подключение Nano Banana и генерация фотореалистичных изображений не реализованы. Размеры берутся из исходной разметки и масштаба; при импорте SVG 1 единица = 0,01 м. Высоты остаются заданными исходным движком: стены 2,2 м, двери 2 м. Это экспериментальная визуализация, а не BIM-проверка конструкции. В исходном движке нет столкновений со стенами.

## Проверка

После `npm run build` и `npm run dev` откройте `/tests/geometry.html`. Проверка строит все три сцены, проверяет конечность координат и индексов геометрии, сохранение параметров при повторном разборе, отклонение неподдерживаемых SVG, загрузку модели glTF после разделения буферов.

Прогулку, мебель и панорамы проверяйте в браузере с WebGL 2. Проверочный облачный браузер в сессии разработки не предоставлял WebGL, поэтому визуальный рендер и экспорт панорам не были проверены в нём. Геометрические проверки и производственная сборка выполнены успешно.
